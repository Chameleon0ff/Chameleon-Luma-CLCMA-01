# Chameleon Luma CLCMA-01


# Контроль якості ніколи не був настільки доступним!

**Колориметр Chameleon Luma** спеціально розроблений для легшого отримання якісного контролю якості як на виробництвах кави, так і для домашнього використання прос'юмерами.

Використовуючи комерційні сенсори відбиття ближнього інфрачервоного випромінювання, **колориметр Chameleon Luma** досягає точності вимірювання до ±1 Agtron за шкалою SCAA Agtron.

| Agtron # | SCAA ступінь|
|------|---------|
| >130 | Недорозвинена кава |
| 91-130 | Занадто світла |
| 81-91 | Дуже світла |
| 71-81 | Світла |
| 61-71 | Середньосвітла |
| 51-61 | Середня |
| 41-51 | Середньотемна |
| 31-41 | Темна |
| 15-31 | Дуже темна |
| <15 | Перерозвинута кава |

**Колориметр Chameleon Luma** використовує цикл замірів (4 послідовних вимірювання) для підвищеної точності та робить непотрібними повторні вимірювання того ж зразка кави.

Невеликий об'єм зразка — <4г меленої кави або <9г кавових зерен — зменшує відходи виробництва, що надзвичайно важливо для невеликих виробництв та домашнього використання.

# Chameleon Luma CLCMA-01

# Quality control has never been so accessible!

**The Chameleon Luma** colormeter is specifically designed to make it easier to obtain quality control in both coffee production and home use by prosumers.

Using commercial near-infrared reflectance sensors, the **Chameleon Luma** colormeter achieves measurement accuracy of ±1 Agtron on the SCAA Agtron scale.

| Agtron # | SCAA Grade|
|------|--------|
| >130 | Underdeveloped coffee |
| 91-130 | Extremely light |
| 81-91 | Very light |
| 71-81 | Light |
| 61-71 | Medium light |
| 51-61 | Medium |
| 41-51 | Medium dark |
| 31-41 | Dark |
| 15-31 | Very dark |
| <15 | Overdeveloped coffee |

**Chameleon Luma** colormeter uses a measurement cycle (4 consecutive measurements) for increased accuracy and eliminates the need for repeated measurements of the same coffee sample.

Small sample volume — <4g of ground coffee or <9g of coffee beans — reduces production waste, which is extremely important for small-scale production and home use.
